## 3. 카메라 모드 (화면의 합성 영상 촬영) — 한계

- **측정:** 재생 약 140초(약 2.6바퀴)에서 정답은 입장 약 23, 퇴장 약 5였다. 기기는 **입장 8, 퇴장 5**를 셌다. 입장 재현율은 **약 35%**(추정)다.
- **관찰된 오검출:**
  - 화면에 비친 **조명 반사광**: 학습 데이터의 밝은 머리(흰 모자)와 비슷한 밝은 원형 블롭
  - 화면 밖 **테두리** 영역
  - 방 장면에서 움직이지 않는 가짜 '머리'
- **원인:** 합성 데이터로만 학습해 생긴 **도메인 갭**. 촬영 시의 흐림, 반사, 모아레, 테두리를 학습에서 본 적이 없다.
- **메모리:** 카메라 + 실시간 영상 시청 중 내부 힙 최소 여유가 5.5KB까지 떨어졌다. 아레나를 PSRAM으로 옮겨 해결했다.
- **개선 방향 (미실시):**
  - 반사광·테두리·흐림·모아레를 넣은 증강으로 재학습
  - 재생 페이지가 띄운 프레임을 정답으로 삼아 실촬영 프레임에 자동 라벨링 후 추가 학습
  - 사전학습 모델 사용

## 4. 사전학습 모델 시험 (ESP-DL `pedestrian_detect`, 옆 시점) — 미통합

| 항목 | 결과 |
|---|---|
| 적재 | 가능. 내부 힙 최소 85KB, PSRAM 약 1.24MB 사용. 앱 2.12MB라 앱 영역을 3MB로 늘려야 함 |
| 속도 | 추론 151ms, 약 6.4 FPS |
| 검출 (사람이 카메라 앞을 오간 60초) | 점수 0.5~0.7로 낮음. **0.7 기준 1/381 프레임**, 0.5 기준 76/381 프레임. 빈 방 40프레임에서는 오검출 0 |
| 판단 | 시간 부족으로 통합하지 않음. 점수가 낮은 원인(RGB565 바이트 순서, 조명, 거리)은 미확인 |

## 5. 알려진 한계

- 정확도는 합성 데이터 기준이다. 실제 카메라에서는 도메인 갭이 크다 (3절).
- 머리가 실제로 겹친 2인(`occluded_pair`)은 0.267로, 한 명으로 센다 (게이트 제외 범주).
- 장기 체류 확정값은 손님이 계속 드나들면 늦어진다 (구조적 한계, `07-database.md` 4.2절).
- 동반입장 판정은 이벤트가 끊임없이 이어지면 세션이 길어져 초과 인원이 묻힐 수 있다.
